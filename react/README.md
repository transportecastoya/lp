# Transporte Castoya — aplicación React

Esta carpeta contiene la implementación activa de la landing page de Transporte Castoya.

- Sitio: <https://transportecastoya.github.io/lp/>
- Despliegue: <https://github.com/transportecastoya/lp/actions/workflows/deploy-pages.yml>
- Documentación completa: [`../README.md`](../README.md)

## Inicio rápido

Requiere Node.js 20 y npm.

```bash
npm ci
npm run dev
```

## Verificación

```bash
npm run typecheck
npm run build
npm run preview
```

Los enlaces de la página se editan en `src/data/content.ts`; los recursos estáticos y metadatos auxiliares se encuentran en `public/`.
